# Lab 0 — Native Node.js Website

A tiny home page served by a native Node.js HTTP server.
No frameworks (no Express, no React).

## Files

- `server.js` — native Node HTTP server
- `public/index.html` — the home page
- `public/style.css` — styling
- `public/app.js` — client-side button toggle

## Run locally

```cmd
npm install
node server.js
